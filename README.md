## ⚙️Использование

1. Сначала активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика DNS, отличный от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы - [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, настройка и работа Secure DNS на компьютере могут нарушиться

2. Перейдите на [страницу последнего релиза](https://github.com/VanquisherBatDoor/zapret-discord-youtube/releases/latest) и скачайте архив zip/rar

3. Откройте свойства загруженного архива и отметьте "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите необходимый файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для включения автозапуска используйте **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) - ручной запуск выбранной стратегии

  Ручной запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий именно для вас**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск (services.msc)</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из служб
  - **`Check Status`** - просмотр состояния обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** - смена режима обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию нужно перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - смена режима обхода ресурсов из `ipset-all.txt`.  
  Это пригодится при проверке ресурса, который без zapret работает, а с ним - нет.  
  В скобках показывается выбранный режим:
    - `none` - ни один IP не проходит проверку
    - `loaded` - IP сверяется со списком
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включение или отключение автоматического поиска обновлений
  - **`Replace active fakes`** - замена используемого фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** - загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** - ручная проверка обновлений
  - **`Run Diagnostics`** - поиск распространённых причин неработоспособности zapret.  
  В конце процедуры можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работу клиента после неожиданного сбоя
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - проверка сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не появляется

- При запуске стратегии отдельным bat-файлом, а не через service, должен запуститься winws.exe (обход), видимый в панели задач.  
Если этого не случилось, обратитесь к [#522](https://github.com/VanquisherBatDoor/zapret-discord-youtube/issues/522)

### Подходящей стратегии нет
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если имеющийся hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - Откройте файл `hosts` в созданной папке через текстовый редактор, запущенный от имени администратора
  - Вставьте скопированный текст в конец `hosts` либо замените ранее добавленные аналогичные строки
  - Сохраните изменения и проверьте соединение. Если результата нет, убедитесь, что файл действительно был сохранён.

#### Результат не гарантируется. При отсутствии эффекта используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/VanquisherBatDoor/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или раньше работал, а теперь нет

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Найденная стратегия способна работать некоторое время, а затем перестать обходить блокировку после обнаружения.
> В репозитории есть много разных стратегий. Если ни одна не подходит, создайте новую на основе одной из них, изменив её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не показывает ошибок

- Проверьте наличие адреса ресурса в списках доменов или IP

- Испытайте другие стратегии, например **`ALT`** или **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/VanquisherBatDoor/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезапустите устройство
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их, затем в конце выберите Y
- Удалите текущую папку zapret
- Скачайте свежий архив `zapret-discord-youtube-...` [со страницы релизов](https://github.com/VanquisherBatDoor/zapret-discord-youtube/releases)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть пункт разблокировки, отметьте его, нажмите «Применить» и «ОК»
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов
- Запускайте разные `general`-скрипты и проверяйте интернет-ресурсы. Если выбранный вариант не работает, закройте программу через значок замка в панели задач и попробуйте следующую стратегию
- После выбора рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Игра или приложение не работает при включённом zapret

- Проверьте в `service.bat`, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может повлиять на неожиданные для вас ресурсы.

### Античит сообщает о WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть в службах

1. Получите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите службу, подставив имя из предыдущего шага:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Переберите остальные стратегии, особенно если раньше доступ работал.
- Дополнительные сведения есть в [#251](https://github.com/VanquisherBatDoor/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её
- В `service.bat` выберите `Run Diagnostics`, затем очистите кэш Discord
- Проверьте приложение Discord и определите, помогла ли очистка кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, временно пользуйтесь ей
- Если браузер тоже не подключается, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/VanquisherBatDoor/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/VanquisherBatDoor/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не подключаются игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Наиболее общий порядок действий:
- обновите ipset через `service.bat` и включите `Game Filter`
- если это не помогло, дополнительно включите режим `ipset any`

Учтите: при `ipset any` многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/VanquisherBatDoor/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

- Сообщите о ней [здесь](https://github.com/VanquisherBatDoor/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Расширить список обхода можно через следующие файлы:
- **`list-general-user.txt`** - домены, включая их поддомены
- **`list-exclude-user.txt`** - домены, которые нужно исключить; это полезно, например, когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - исключаемые IP-адреса и подсети
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
